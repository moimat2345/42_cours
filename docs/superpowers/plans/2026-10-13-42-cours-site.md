# 42 Cours — Plan d'implémentation

> **Pour les agents d'exécution :** SOUS-SKILL REQUIS : utiliser superpowers:subagent-driven-development (recommandé) ou superpowers:executing-plans pour exécuter ce plan tâche par tâche. Les étapes utilisent des cases à cocher (`- [ ]`).

**Objectif :** un site statique bilingue (FR/EN), déployable sur Vercel, avec un cours interactif par projet 42 de Mateo (17 cours + 1 extra).

**Architecture :** des fragments HTML par cours (`content/courses/<id>/{fr,en}.html`) sont emballés par un script Node sans dépendance (`build.mjs`) dans des gabarits communs ; l'accueil est généré depuis `content/projects.json`. Les démos sont des scripts navigateur partagés FR/EN (`assets/demos/`), détectés automatiquement via `data-demo="…"`. Sortie : HTML statique dans `dist/`.

**Stack :** Node ≥ 18 (ES modules, `node:test`), HTML/CSS/JS vanille, Google Fonts (seule ressource externe autorisée), Vercel.

**Spec :** `docs/superpowers/specs/2026-10-13-42-cours-design.md`

## Écart assumé par rapport au spec

Le spec listait un champ `demos` dans `projects.json`. Ce plan le supprime : le build détecte les démos en lisant les `data-demo="…"` du fragment. Cela évite que 15 agents en parallèle modifient le même fichier JSON. Le spec a été aligné (exemple de `projects.json`).

## Contraintes globales

- Node ≥ 18, `"type": "module"`, **zéro dépendance npm** (aucun `npm install`).
- Polices : Chakra Petch, Sora, JetBrains Mono via Google Fonts. Aucune autre ressource externe (`<script src>` ou `<link href>` vers un autre hôte interdit).
- FR + EN livrés ensemble ; le build `--strict` échoue si un fragment FR ou EN manque.
- Contenu **basé sur le sujet / l'exercice**, pas sur le code de Mateo. Une section « Comment je l'ai fait » courte (150 mots max), en prose, sans listing de code.
- Au moins **2 démos interactives** par cours (1 si le cours est très court), sans bibliothèque externe, utilisables au clavier.
- Thème sombre existant ; gouttière mobile de 16 px ; aucune page ne doit défiler horizontalement à 375 px.
- **Aucun `git commit`, `git push` ni `vercel` sans demande explicite de Mateo** (spec §2). Les tâches se terminent donc par une vérification, pas par un commit.
- Ids de projet : `libft`, `ft_printf`, `get_next_line`, `born2beroot`, `push_swap`, `pipex`, `minishell`, `fractol`, `philosophers`, `netpractice`, `cub3d`, `cpp00`…`cpp05`. Extra : `public-vs-private`.
- Les sources de Mateo sont en **lecture seule** ; ne jamais modifier `/Users/mateon/Documents/clean_github/` ni `42bangkok_course/`.

## Points de revue prioritaires

Cinq situations que le spec implique mais qu'aucune tâche « fonctionnelle » ne couvre d'elle-même. Chacune a un test dans la tâche indiquée.

1. Un fragment contenant `$&`, `$1` ou du texte `{{x}}` (exemples C, gabarits) doit apparaître **tel quel** dans la page — Tâche 2.
2. Un nom ou résumé avec `'`, `&` ou `<` (ex. `fract'ol & co`) doit être échappé dans le texte, les attributs et le `<title>` — Tâche 2.
3. Une `<section>` sans `<h2>`, ou un id déjà pris (`sec-1`), ne doit ni planter ni produire d'id dupliqué — Tâche 1.
4. Une démo référencée dont le JS manque ou a une erreur de syntaxe, un JSON i18n invalide ou des clés i18n qui diffèrent entre FR et EN doivent être détectés avant déploiement — Tâche 5.
5. Un visiteur sans JavaScript ou avec `localStorage` bloqué doit pouvoir lire tout le contenu et naviguer ; aucune page ne doit déborder à 375 px — Tâche 4 (contrôle navigateur) et Tâche 27 (toutes les pages).

`lib/html.mjs` :

```js
const ESC = { '&': '&amp;', '<': '&lt;', '>': '&gt;', '"': '&quot;', "'": '&#39;' };

export function escapeHtml(s) {
  return String(s).replace(/[&<>"']/g, (c) => ESC[c]);
}

// {{name}} is HTML-escaped, {{{name}}} is inserted as-is. A missing variable is a bug: throw.
// The replacer is a function so "$&" or "$1" inside a value are never interpreted.
export function fill(template, vars) {
  return template.replace(/\{\{\{\s*(\w+)\s*\}\}\}|\{\{\s*(\w+)\s*\}\}/g, (_, raw, esc) => {
    const key = raw || esc;
    if (!(key in vars)) throw new Error(`Template variable not provided: ${key}`);
    return raw ? String(vars[key]) : escapeHtml(vars[key]);
  });
}
```

`lib/toc.mjs` :

```js
const stripTags = (s) =>
  s
    .replace(/<small\b[^>]*>[\s\S]*?<\/small>/g, '')
    .replace(/<[^>]*>/g, '')
    .replace(/&amp;/g, '&')
    .replace(/&nbsp;/g, ' ')
    .replace(/\s+/g, ' ')
    .trim();

// Gives every titled <section> an id (keeps an existing one) and returns the table of contents.
export function buildToc(html) {
  const items = [];
  const used = new Set([...html.matchAll(/\bid="([^"]+)"/g)].map((m) => m[1]));
  let n = 0;
  const out = html.split(/(?=<section\b)/).map((part) => {
    const open = part.match(/^<section\b([^>]*)>/);
    if (!open) return part;
    const h2 = part.match(/<h2\b[^>]*>([\s\S]*?)<\/h2>/);
    if (!h2) return part;
    let id = (open[1].match(/\bid="([^"]+)"/) || [])[1];
    if (!id) {
      do {
        n += 1;
        id = `sec-${n}`;
      } while (used.has(id));
      used.add(id);
      part = `<section id="${id}"${open[1]}>` + part.slice(open[0].length);
    }
    items.push({ id, label: stripTags(h2[1]) });
    return part;
  });
  return { html: out.join(''), items };
}
```

import { existsSync, readFileSync } from 'node:fs';
import { join } from 'node:path';

export const LANGS = ['fr', 'en'];
export const GROUP_ORDER = ['c', 'sys', 'gfx', 'cpp'];

const readJson = (root, rel) => JSON.parse(readFileSync(join(root, rel), 'utf8'));
const byOrder = (a, b) => a.order - b.order;

export const loc = (v, lang) => (v && typeof v === 'object' ? v[lang] : v);

export const loadProjects = (root) => readJson(root, 'content/projects.json').sort(byOrder);
export const loadExtras = (root) => readJson(root, 'content/extras.json').sort(byOrder);
export const loadUi = (root) => readJson(root, 'content/ui.json');

export function readFragment(root, kind, id, lang) {
  const dir = kind === 'extras' ? 'extras' : 'courses';
  const file = join(root, 'content', dir, id, `${lang}.html`);
  return existsSync(file) ? readFileSync(file, 'utf8') : null;
}

import { readFileSync } from 'node:fs';
import { join } from 'node:path';

// UI strings read directly by lib/pages.mjs (not through a template placeholder).
export const LIB_UI_KEYS = [
  'badgeReady', 'badgeSoon', 'prev', 'next', 'tocLabel', 'fallbackBanner',
  'group_all', 'group_c', 'group_sys', 'group_gfx', 'group_cpp',
];

export function templateUiKeys(root) {
  const keys = new Set();
  for (const name of ['home', 'course']) {
    const text = readFileSync(join(root, 'templates', `${name}.html`), 'utf8');
    for (const m of text.matchAll(/\{\{\{?\s*ui_(\w+)\s*\}?\}\}/g)) keys.add(m[1]);
  }
  return [...keys];
}

export const requiredUiKeys = (root) => [...new Set([...LIB_UI_KEYS, ...templateUiKeys(root)])].sort();

export function resolveCourse({ root, kind, item, lang, strict }) {
  const own = readFragment(root, kind, item.id, lang);
  if (own !== null) return { body: own, fallback: false, ready: true };
  if (strict) throw new Error(`Missing ${lang} fragment for ${kind}/${item.id}`);
  const fr = lang === 'fr' ? null : readFragment(root, kind, item.id, 'fr');
  if (fr !== null) return { body: fr, fallback: true, ready: true };

export function renderCard({ item, kind, lang, ui, ready }) {
  const inner =
    `<span class="pcard-ic" aria-hidden="true">${esc(item.icon)}</span>` +
    `<span class="pcard-tag">${esc(loc(item.tag, lang))}</span>` +
    `<h3>${esc(loc(item.name, lang))}</h3>` +

export function renderCourse({ tpl, root, ui, lang, kind, item, list, resolved }) {
  const r = resolved[`${kind}/${item.id}`];
  const { html: body, items: toc } = buildToc(r.body);
  const demos = detectDemos(body);
  const idx = list.findIndex((x) => x.id === item.id);
  const nearest = (step) => {
    for (let i = idx + step; i >= 0 && i < list.length; i += step) {
      if (resolved[`${kind}/${list[i].id}`].ready) return list[i];
    }
    return null;
  };

  const tocLinks = toc.map((t) => `<a href="#${esc(t.id)}">${esc(t.label)}</a>`).join('');

    ...langVars(lang, path),

    prev: pager(nearest(-1), 'pager-prev', ui.prev),

export function build({ root, out = join(root, 'dist'), strict = false, withTemplate = false }) {

  );
  const kinds = [['courses', projects], ['extras', extras]];

  rmSync(out, { recursive: true, force: true });
  for (const lang of LANGS) {
    const resolved = {};
    for (const [kind, list] of kinds) {

    }
    write(join(out, lang, 'index.html'), renderHome({ tpl: tpl.home, ui: uiAll[lang], lang, projects, extras, resolved }));
    for (const [kind, list] of kinds) {
      for (const item of list) {
        if (!resolved[`${kind}/${item.id}`].ready) continue;
        const dir = kind === 'extras' ? join(out, lang, 'extras', item.id) : join(out, lang, item.id);
        write(join(dir, 'index.html'), renderCourse({ tpl: tpl.course, root, ui: uiAll[lang], lang, kind, item, list, resolved }));
      }
    }
  }
  cpSync(join(root, 'assets'), join(out, 'assets'), { recursive: true });
  if (existsSync(join(root, 'public'))) cpSync(join(root, 'public'), out, { recursive: true });
  write(join(out, 'index.html'), tpl.root);
}

}

import { readFileSync } from 'node:fs';
import { join } from 'node:path';
import { GROUP_ORDER, LANGS } from './content.mjs';
import { requiredUiKeys } from './ui-keys.mjs';

const HEX = /^#[0-9a-fA-F]{3,8}$/;
const ID = /^[a-z0-9_-]+$/;

function checkItems(list, label, groups, errors) {
  if (!Array.isArray(list)) {
    errors.push(`${label}: must be an array`);
    return;
  }
  const ids = new Set();
  const orders = new Set();
  list.forEach((it, i) => {
    const at = `${label}[${i}] (${it && it.id})`;
    if (!it || !ID.test(it.id || '')) errors.push(`${at}: id must match ${ID}`);
    else if (ids.has(it.id)) errors.push(`${at}: duplicate id`);
    else ids.add(it.id);
    if (!groups.includes(it.group)) errors.push(`${at}: group must be one of ${groups.join(', ')}`);
    if (!Number.isFinite(it.order)) errors.push(`${at}: order must be a number`);
    else if (orders.has(it.order)) errors.push(`${at}: duplicate order ${it.order}`);
    else orders.add(it.order);
    if (!it.icon) errors.push(`${at}: icon is required`);
    if (!HEX.test(it.accent || '')) errors.push(`${at}: accent must be a hex colour`);
    for (const f of ['tag', 'summary']) {
      for (const lang of LANGS) {
        if (!it[f] || !String(it[f][lang] || '').trim()) errors.push(`${at}: ${f}.${lang} is required`);
      }
    }
    const nameOk = typeof it.name === 'string' ? it.name.trim() : LANGS.every((l) => it.name && String(it.name[l] || '').trim());
    if (!nameOk) errors.push(`${at}: name is required (string or {fr,en})`);
  });
}

export function validateContent(root) {
  const errors = [];
  const read = (rel) => {
    try {
      return JSON.parse(readFileSync(join(root, rel), 'utf8'));
    } catch (e) {
      errors.push(`${rel}: ${e.message}`);
      return null;
    }
  };
  const projects = read('content/projects.json');
  const extras = read('content/extras.json');
  const ui = read('content/ui.json');
  if (projects) checkItems(projects, 'projects', GROUP_ORDER, errors);
  if (extras) checkItems(extras, 'extras', ['extras'], errors);
  if (ui) {
    const need = requiredUiKeys(root);
    for (const lang of LANGS) {
      for (const k of need) {
        if (!ui[lang] || !String(ui[lang][k] || '').trim()) errors.push(`ui.${lang}.${k} is missing`);
      }
    }
    const [a, b] = LANGS.map((l) => new Set(Object.keys(ui[l] || {})));
    for (const k of a) if (!b.has(k)) errors.push(`ui.en.${k} is missing (present in fr)`);
    for (const k of b) if (!a.has(k)) errors.push(`ui.fr.${k} is missing (present in en)`);
  }
  return errors;
}

```js
import { existsSync, readdirSync, readFileSync, statSync } from 'node:fs';
import { dirname, join, relative, resolve } from 'node:path';
import { spawnSync } from 'node:child_process';
import { fileURLToPath } from 'node:url';
import { validateContent } from '../lib/validate.mjs';

const ALLOWED_HOSTS = ['fonts.googleapis.com', 'fonts.gstatic.com'];

function walk(dir, out = []) {
  for (const name of readdirSync(dir)) {
    const p = join(dir, name);
    if (statSync(p).isDirectory()) walk(p, out);
    else out.push(p);
  }
  return out;
}

function target(dist, url) {
  const clean = decodeURIComponent(url.split('#')[0].split('?')[0]);
  const base = join(dist, clean);
  if (clean.endsWith('/')) return existsSync(join(base, 'index.html'));
  return (existsSync(base) && statSync(base).isFile()) || existsSync(join(base, 'index.html'));
}

// { demoName: sorted i18n keys | null (no block) | 'invalid' }
function demoI18n(html) {
  const out = {};
  for (const part of html.split('data-demo="').slice(1)) {
    const name = part.slice(0, part.indexOf('"'));
    const m = part.match(/<script\b[^>]*class="demo-i18n"[^>]*>([\s\S]*?)<\/script>/);
    if (!m) { out[name] = out[name] ?? null; continue; }
    try { out[name] = Object.keys(JSON.parse(m[1])).sort(); } catch { out[name] = 'invalid'; }
  }
  return out;
}

const ids = (html) => [...html.matchAll(/\sid="([^"]+)"/g)].map((m) => m[1]);
const demoNames = (html) => [...new Set([...html.matchAll(/data-demo="([\w-]+)"/g)].map((m) => m[1]))];

export function check({ root, dist = join(root, 'dist'), only = null }) {
  const errors = [];
  if (!existsSync(dist)) return [`${dist} not found: run "npm run build" first`];
  const pages = walk(dist).filter((f) => f.endsWith('.html')).filter((f) => {
    const rel = relative(dist, f);
    return rel === 'index.html' || rel.startsWith('fr/') || rel.startsWith('en/');
  });
  const htmlOf = new Map(pages.map((f) => [relative(dist, f), readFileSync(f, 'utf8')]));

  for (const [rel, html] of htmlOf) {
    const dir = rel.split('/')[0];
    if ((dir === 'fr' || dir === 'en') && !new RegExp(`<html lang="${dir}"`).test(html)) errors.push(`${rel}: <html lang> must be "${dir}"`);
    if (!/<title>[^<]*\S[^<]*<\/title>/.test(html)) errors.push(`${rel}: empty or missing <title>`);

    const seen = new Set();
    for (const id of ids(html)) {
      if (seen.has(id)) errors.push(`${rel}: duplicate id "${id}"`);
      seen.add(id);
    }
    for (const m of html.matchAll(/\b(?:href|src)="(\/(?!\/)[^"]*)"/g)) {
      if (!target(dist, m[1])) errors.push(`${rel}: broken link ${m[1]}`);
    }
    for (const m of html.matchAll(/\bhref="#([^"]+)"/g)) {
      if (!seen.has(m[1])) errors.push(`${rel}: anchor #${m[1]} has no target`);
    }
    for (const m of html.matchAll(/<script\b[^>]*\bsrc="((?:https?:)?\/\/[^"]+)"/g)) errors.push(`${rel}: external script ${m[1]}`);
    for (const m of html.matchAll(/<link\b[^>]*\bhref="(https?:\/\/([^/"]+)[^"]*)"/g)) {
      if (!ALLOWED_HOSTS.includes(m[2])) errors.push(`${rel}: external resource ${m[1]}`);
    }
    for (const name of demoNames(html)) {
      if (!existsSync(join(dist, 'assets/demos', `${name}.js`))) errors.push(`${rel}: demo "${name}" is missing assets/demos/${name}.js`);
    }
    if (/class="demo-i18n"/.test(html) && Object.values(demoI18n(html)).includes('invalid')) {
      errors.push(`${rel}: invalid demo-i18n JSON`);
    }
  }

  const demosDir = join(dist, 'assets/demos');
  if (existsSync(demosDir)) {
    for (const f of readdirSync(demosDir).filter((n) => n.endsWith('.js'))) {
      const r = spawnSync(process.execPath, ['--check', join(demosDir, f)], { encoding: 'utf8' });
      if (r.status !== 0) errors.push(`assets/demos/${f}: syntax error — ${String(r.stderr).split('\n').find((l) => /Error/.test(l)) || 'node --check failed'}`);
    }
  }

  for (const [rel, fr] of htmlOf) {
    if (!rel.startsWith('fr/')) continue;
    const en = htmlOf.get(rel.replace(/^fr\//, 'en/'));
    if (en === undefined) continue;
    const sections = (h) => (h.match(/<section\b/g) || []).length;
    if (sections(fr) !== sections(en)) errors.push(`${rel}: parity — FR has ${sections(fr)} <section>, EN has ${sections(en)}`);
    const a = ids(fr).sort().join(',');
    const b = ids(en).sort().join(',');
    if (a !== b) errors.push(`${rel}: parity — FR and EN ids differ`);
    const fa = demoI18n(fr);
    const fb = demoI18n(en);
    for (const name of new Set([...Object.keys(fa), ...Object.keys(fb)])) {
      if (JSON.stringify(fa[name]) !== JSON.stringify(fb[name])) errors.push(`${rel}: i18n keys differ for demo "${name}"`);
    }
  }

  return only ? errors.filter((e) => e.includes(`/${only}/`) || e.includes(`${only}-`) || e.includes(`"${only}-`)) : errors;
}

if (process.argv[1] && resolve(process.argv[1]) === fileURLToPath(import.meta.url)) {
  const args = process.argv.slice(2);
  const arg = (name) => (args.includes(name) ? args[args.indexOf(name) + 1] : null);
  const root = join(dirname(fileURLToPath(import.meta.url)), '..');
  const only = arg('--only');
  const errors = [...(only ? [] : validateContent(root)), ...check({ root, dist: arg('--dist') ? resolve(arg('--dist')) : join(root, 'dist'), only })];
  if (errors.length) {
    console.error(errors.map((e) => `✗ ${e}`).join('\n'));
    process.exit(1);
  }
  console.log('OK');
}

(window.Demos = window.Demos || {})['bit-toggler'] = function (root, T) {
  var n = Math.min(32, Math.max(1, parseInt(root.getAttribute('data-bits') || '8', 10)));
  var bits = [];
  for (var i = 0; i < n; i++) bits.push(0);

  var mount = root.querySelector('.demo-mount');
  mount.classList.add('demo-body');
  mount.textContent = '';

  var title = document.createElement('p');
  title.className = 'bt-title';
  title.textContent = T.title || '';

  var row = document.createElement('div');
  row.className = 'bt-row';
  row.setAttribute('role', 'group');
  row.setAttribute('aria-label', T.title || 'bits');

  var out = document.createElement('p');
  out.className = 'bt-out';
  out.setAttribute('aria-live', 'polite');

  var reset = document.createElement('button');
  reset.type = 'button';
  reset.className = 'bt-reset';
  reset.textContent = T.reset || 'reset';

  function value() {
    var v = 0;
    for (var i = 0; i < n; i++) v = v * 2 + bits[i]; // bits[0] is the most significant bit
    return v;
  }
  function render() {
    var v = value();
    out.textContent = (T.decimal || 'decimal') + ': ' + v + '   ' + (T.hex || 'hex') + ': 0x' + v.toString(16).toUpperCase();
    Array.prototype.forEach.call(row.children, function (b, i) {
      b.textContent = String(bits[i]);
      b.setAttribute('aria-pressed', String(bits[i] === 1));
      b.classList.toggle('on', bits[i] === 1);
    });
  }

  bits.forEach(function (_, i) {
    var b = document.createElement('button');
    b.type = 'button';
    b.className = 'bt-bit';
    b.setAttribute('aria-label', (T.bit || 'bit') + ' ' + (n - 1 - i));
    b.addEventListener('click', function () { bits[i] ^= 1; render(); });
    row.appendChild(b);
  });
  reset.addEventListener('click', function () {
    for (var i = 0; i < n; i++) bits[i] = 0;
    render();
  });

  mount.appendChild(title);
  mount.appendChild(row);
  mount.appendChild(out);
  mount.appendChild(reset);
  render();
};
```

# Écrire un cours

**Public :** quelqu'un qui a le projet 42 à faire et veut comprendre **comment s'y prendre**. Il a le sujet PDF sous les yeux. Le cours explique le sujet et la démarche ; il ne décortique pas le code de Mateo.

## 1. Ce que tu crées (et rien d'autre)

- `content/courses/<id>/fr.html` : fragment HTML (pas de `<html>`, `<head>`, `<body>`). Le build ajoute la barre du haut, le sommaire, le précédent/suivant et le pied.
- `assets/demos/<id>-<nom>.js` (+ `.css` si besoin) : un fichier par démo. Préfixe `<id>-` obligatoire. Seule exception : `bit-toggler`, démo partagée.
- Ne modifie **jamais** `content/projects.json`, `content/ui.json`, `lib/`, `templates/`, `assets/site.*`, ni les cours des autres.
- Les sources de Mateo sont en lecture seule.

## 2. Structure d'un cours

Pars de `content/courses/_template/fr.html` (visible en dev sur `/fr/_template/`). Sections, avec **ids stables** (identiques en FR et EN) :

| id | Section | Contenu |
|---|---|---|
| `overview` | Le projet en bref | Ce qu'on te demande, en 3-4 lignes |
| `map` | La carte du projet | Obligatoire / bonus, fichiers à rendre, fonctions autorisées, contraintes (flags, Norme) |
| `concepts` (ou plusieurs ids) | Concepts clés | Schémas, démos interactives, extraits de code **courts** |
| `steps` (ou `ex00`, `ex01`…) | Étape par étape | Comment s'y prendre, par fonction ou par exercice |
| `pitfalls` | Pièges classiques | Ce qui fait échouer en correction |
| `how` | Comment je l'ai fait | 150 mots max, en prose, l'approche et les choix. **Aucun listing de code** |
| `recap` | À retenir (défense d'éval) | Liste de points + checklist |

Pour un module C++ : une section par exercice, avec fichiers à rendre, squelette de header (déclarations uniquement) et résultat attendu, comme le cours CPP05.

## 3. Règles de rédaction

- Tutoiement, ton direct, phrases courtes. Jargon technique en anglais quand c'est l'usage (`stack`, `heap`, `buffer`).
- **Partir du sujet.** Chaque affirmation sur le sujet (fonctions autorisées, flags, formats de sortie, seuils) doit être vérifiable dans le PDF. Si une valeur n'est pas dans le sujet, ne l'invente pas.
- **Donner de quoi réussir le sien sans livrer une solution à copier.** Pas de fonction complète prête à coller. Des extraits courts pour illustrer une idée sont acceptés.
- Pas de « ton code » : on parle de « ton `ft_split` », « ton exercice », à la 2ᵉ personne générique.
- Pour « Comment je l'ai fait » : lis le repo de Mateo pour comprendre son approche, puis résume-la en prose.
- Emojis avec parcimonie (titres de section, encarts), comme dans les pages existantes.

## 4. Conventions HTML

- Hero : `header.hero` > `span.kicker(span.dot)` + `h1.title(span.g)` + `p.lead` + `p.subj`. Puis `<div class="wrap">` qui contient les `<section>`.
- Chaque section : `<section id="…"><div class="sec-head reveal"><span class="sec-num">01</span><h2>Titre <span class="accent">accentué</span></h2></div> …`. Le `<h2>` alimente le sommaire. Un sous-titre éventuel va dans `<small>` (ignoré par le sommaire).
- Texte : `p.body`, `code.inline`, `b`.
- Code : `.editor` > `.bar` (`.lights`, `.fname`) + `pre` ; coloration par `span` : `.k` `.ty` `.fn` `.st` `.cm` `.nm` `.op`.
- Grilles : `.map` > `.map-item` (`.ex`, `h4`, `p`) ; `.duo` > `.card` ; tableaux : `.table-wrap` > `table`.
- Encarts : `.callout` (info), `.callout.warn` (piège), `.how`, `.cheat` (récap, liste `li` avec `.chk`).
- Étapes : `.steps` > `.step.on` (`.n`, `.txt`).
- Les couleurs viennent de `var(--accent)` (couleur du projet) et des tokens de `assets/site.css`.

## 5. Démos interactives (la marque de fabrique)

Au moins **deux** par cours (une seule si le cours est très court). Elles doivent faire comprendre en manipulant : l'utilisateur change une entrée, voit le résultat se transformer.

Dans le fragment :

```html

import { dirname, resolve } from 'node:path';
import { fileURLToPath } from 'node:url';

// Turns a standalone course page into a fragment for the shared shell:
// keeps the page's own <style> (minus the nav.top rules) and body, drops what the shell provides.
export function migrate(html) {
  const css = [...html.matchAll(/<style\b[^>]*>([\s\S]*?)<\/style>/g)]
    .map((m) => m[1])
    .join('\n')
    .replace(/[ \t]*nav\.top[^{}]*\{[^{}]*\}\n?/g, '')
    .replace(/(^|[\s,}])\.reveal(?=[.{\s,])/g, '$1.js .reveal');
  const body = (html.match(/<body[^>]*>([\s\S]*)<\/body>/) || [, ''])[1]
    .replace(/<nav class="top">[\s\S]*?<\/nav>/, '')
    .replace(/<footer>[\s\S]*?<\/footer>/, '');
  return `<style>\n${css.trim()}\n</style>\n${body.trim()}\n`;
}

if (process.argv[1] && resolve(process.argv[1]) === fileURLToPath(import.meta.url)) {
  const [src, dest] = process.argv.slice(2);
  if (!src || !dest) {
    console.error('usage: node scripts/migrate-page.mjs <source.html> <destination.html>');
    process.exit(1);
  }
  mkdirSync(dirname(resolve(dest)), { recursive: true });
  writeFileSync(dest, migrate(readFileSync(src, 'utf8')));
  console.log(`migrated ${src} → ${dest}`);
}
```
